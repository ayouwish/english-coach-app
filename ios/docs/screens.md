## 1. 登录

### 1.1 目标与入口
首次启动、会话过期、主动退出后进入。

### 1.2 布局

```
┌────────────────────────────────┐
│            🎈 (Logo)            │
│        English Coach           │
│   和家人一起，把英语说出来        │
│                                │
│  ┌──────────────────────────┐  │
│  │ 邮箱                      │  │
│  └──────────────────────────┘  │
│  ┌──────────────────────────┐  │
│  │ 密码              [👁]    │  │
│  └──────────────────────────┘  │
│  [        登录        ]         │
│                                │
│  ▸ 服务器设置（折叠，默认隐藏）    │
│    地址：https://…/api          │
│    [测试连接]                   │
└────────────────────────────────┘
```

### 1.3 交互
- 邮箱键盘 `.emailAddress`、`textContentType = .username`；密码 `.password`、`textContentType = .password`；登录按钮在两者非空时可用。
- `keyboardType`/`submitLabel`：密码回车直接提交；提交中按钮变 loading，禁止重复点击。
- 成功后**必须**再调 `GET /auth/me` 拿角色与能力，再决定 Tab；不要用登录响应里的推测字段。
- “记住邮箱”只存 Keychain（上次登录邮箱），**不存密码**；密码框不自动填充已保存密码（避免共用设备泄露）。
- 登录失败 `401`：`邮箱或密码不正确`，焦点回到密码框并全选。
- 服务器设置：默认**完全隐藏**（连点 Logo 5 次或长按版本号才展开），避免孩子在共用设备上误改；登录后由 设置 → 服务器 管理，且仅 `role=parent` 可改。**【客户端自行实现】**

### 1.4 API

| 调用 | 用途 | 备注 |
| --- | --- | --- |
| `POST /auth/login` | 建立 Cookie 会话 | 请求体 `{email,password}`；响应状态码决定成功与否 |
| `GET /auth/me` | 拉取 profile（role/ageBand/cefrLevel/avatar） | 决定 Tab 与能力 |
| `GET /health` | “测试连接”按钮 | 显示 `db` / `voice.reachable` 勾叉 |

### 1.5 状态

| 状态 | 表现 |
| --- | --- |
| loading | 按钮内 spinner + “正在登录…”；输入框禁用 |
| 凭据错误 | 密码框下方红色内联文案（成人）/ 中性文案“再检查一下邮箱和密码哦”（孩子场景罕见） |
| 服务器不可达 | 表单上方横幅：“连不上学习服务器。确认手机连着家里的 Wi-Fi，且 NAS 已开机。” + “重试” + “改服务器地址” |
| 网络离线 | 横幅“当前没有网络”，登录按钮禁用 |
| 已登录但 `/auth/me` 失败 | 不进入主界面；提示“登录成功但读取账号失败”，提供重试 |
| empty | 不适用 |

### 1.6 儿童/成人差异
登录页**统一**（孩子通常由家长登录后交给孩子，或用自己的账号登录）。不做“孩子头像点选登录”——没有对应 API，且弱化密码不安全。若后续要做，需【待后端新增】设备绑定/儿童 PIN，见开放问题 Q4。

## 2. 练习首页（选句）

### 2.1 目标
用最少的点击进入“说一句”，同时暴露连读、盲测、成长三个入口。

### 2.2 布局

```
┌────────────────────────────────┐
│ 你好，Amy 🌟            [⚙️]     │
│ 今天想练点什么？                 │
│ ┌────────┐┌────────┐┌────────┐ │
│ │ 跟读    ││ 连读    ││ 盲测    │ │  ← 三张入口卡（孩子：大卡片两列）
│ │ 一句一句 ││ 连续说  ││ 听音选择 │ │
│ └────────┘└────────┘└────────┘ │
│ ┌────────────────────────────┐ │
│ │ 我的成长 · 3 个音要练  →     │ │  ← 诊断摘要（有数据才显示）
│ └────────────────────────────┘ │
│  难度  [A1][A2][B1][B2]         │
│  筛选  [全部][错音本][最爱音素]   │  ← 错音本仅在有数据时
│  ┌────────────────────────────┐│
│  │ The cat sat on the mat.    ││
│  │ 猫坐在垫子上。              ││
│  │ A1 · /æ/ · 短句       [▶]  ││
│  └────────────────────────────┘│
│  …（列表 / 下拉刷新 / 触底加载） │
└────────────────────────────────┘
```

### 2.3 交互
- 难度分段控件默认取 `profile.cefrLevel`；切换即重查 `GET /sentences?level=`。
- 筛选“错音本”：从 `GET /review` 取句子 id 集合，再在本地过滤语料（**【待确认】** `/review` 是否直接返回句子内容；若返回则直接用）。
- 筛选“最爱音素”：用 `GET /diagnosis` 的 `weak_phonemes` 与句子 `focus_phonemes` 求交集，客户端筛选。
- 列表项点击 → 跟读页；行内 ▶ 直接播放正常语速示范（不进入详情），长按可播慢速。
- 下拉刷新：清语料快照后重拉；离线时只读缓存并显示“离线数据”标签。
- 触底分页：**【待确认】** 后端是否支持分页；若响应是完整数组，则客户端一次拉取后本地分页（600 句可接受）。

### 2.4 API

| 调用 | 时机 |
| --- | --- |
| `GET /sentences?level=A2` | 首屏 / 切换难度 / 下拉刷新 |
| `GET /review` | 进入页面（孩子有数据时） |
| `GET /diagnosis` | 进入页面（成长摘要） |
| `POST /tts` | 行内播放示范（命中缓存则不请求） |

### 2.5 状态

| 状态 | 表现 |
| --- | --- |
| loading | 骨架卡片 ×5（保持布局不跳） |
| empty | “这个难度还没有句子” + “换个难度”；若语料整体为空 → “服务器语料库为空，请检查后端” + 重试 |
| error | 全页错误 + 重试 + “检查服务器” |
| offline | 有缓存：正常展示 + 顶部“离线 · 数据可能不是最新”；无缓存：空态引导连 Wi-Fi |
| 部分失败 | 语料成功但诊断失败 → 隐藏成长卡，不报错 |

### 2.6 儿童/成人差异
| 项 | 孩子 | 成人 |
| --- | --- | --- |
| 入口卡 | 2 列大卡，图示 + 4 字标题 | 3 列紧凑卡 |
| 列表项 | 只显示英文 + 中文（小字），不显示音素标签 | 显示 level / 音素 / 标签 |
| 成长卡 | “还有 3 个音在长大 🌱” | “3 个音素掌握度 <60%” |
| 难度 | 默认且锁定为账号等级（家长改），孩子不可切 | 可自由切 |

## 3. 跟读练习（单句）

### 3.1 布局

```
┌────────────────────────────────┐
│ ‹ 返回            A1 · 短句  ⋯  │
│                                │
│ ┌────────────────────────────┐ │
│ │  The cat sat on the mat.   │ │  ← 28–34pt，可点词听发音（M4）
│ │  /ðə kæt sæt ɒn ðə mæt/    │ │  ← 仅成人显示 IPA
│ │  猫坐在垫子上。         [译] │ │  ← 默认显示，可折叠
│ │  重点：/æ/ /t/  [慢速示范][▶]│ │
│ └────────────────────────────┘ │
│                                │
│        ┌──────────────┐        │
│        │   🎤 按下说话  │        │  ← 录音球（孩子 96pt / 成人 80pt）
│        └──────────────┘        │
│        ▁▃▅▇▅▃▁  （电平波形）    │
│                                │
│  ── 结果区（评分后出现）───────── │
│      ⭕ 78       单词：6/6 正确   │  ← 孩子：⭐⭐⭐ + “说得真清楚！”
│   ┌──────────────────────────┐ │
│   │ The ✅ cat ✅ sat ⚠️ …    │ │  ← 词级着色（成人）
│   └──────────────────────────┘ │
│   语调曲线（成人）  ╱╲___╱╲      │
│   问题：/æ/ 张口不够大…          │
│   [再听我的] [重录] [下一句 →]   │
└────────────────────────────────┘
```

### 3.2 交互（关键顺序）

1. 进入页面：并行 `GET /sentences/:id`（可跳过，用列表数据）+ 预取 TTS（normal）。
2. 点录音球 → 权限检查 → 若正在播放则**先停播**（`AudioCoordinator` 保证）→ 开始录音，球体放大 + 触感反馈 + 计时。
3. 再点一次停止（或 60s 自动停）→ 本地校验（≥500ms、非全静音、≤12MB）→ **自动提交** `POST /attempts`（`mode=scripted`）。
4. 提交中：球体换成“评分中”脉冲 + 文案“正在听你的发音…”，禁用重录（但允许“取消等待”，取消后转 async 轮询需服务端支持，本期不做）。
5. 结果返回：先播报式轻触感，结果区滑入；**不自动播放**（避免突然出声），提供“听示范”。
6. 结果可展开：词级明细、音素明细（成人）、issues 逐条中文解释、feedback。
7. 底部固定动作：`再听我的` / `重录` / `下一句`（下一句按当前筛选顺序）。
8. 提交失败：结果区位置显示内联错误 + 主按钮“重试”（重发同一文件，不重录）+ 次按钮“重录”。

### 3.3 API

| 调用 | 参数 | 用途 |
| --- | --- | --- |
| `POST /tts` | `{text, rate: normal\|slow, format: "mp3"}` | 示范音 |
| `POST /attempts` | multipart：audio/sentence_id/reference_text/mode=scripted/duration_ms | 同步评分 |
| `GET /audio/:id` | — | 服务端保存的录音回放（刷新后仍可听） |
| `POST /attempts/:id/retry` | — | `provider_timeout/provider_error` 后重评，不重录 |
| `GET /sentences/:id` | — | 直接从链接进入时补齐句子 |

> 单句用**同步** `/attempts`：一句话评分的等待可接受（估 2–6s，需实测）。若实测 >8s，改为 `async` + 轮询（M1 改动，见 roadmap 风险项）。

### 3.4 状态

| 状态 | 表现 |
| --- | --- |
| 加载句子失败 | 全页错误 + 重试 |
| 录音中 | 波形 + 计时 + “点击结束”；播放按钮禁用 |
| 评分中 | 球体脉冲 + 进度文案（无百分比，避免假进度）；可返回（后台继续？**不**，取消并提示） |
| 结果成功 | 分数/星级 + 词级 + 建议 |
| 评分失败 | 内联错误 + 重试/重录（按 `architecture.md` §5 映射） |
| 无权限 | 权限引导卡替换录音区（见 audio.md §2.3） |
| 离线 | 可听缓存示范；录音后提示“需要服务器才能评分”，保留录音，联网后可重交（M4） |

### 3.5 儿童/成人差异
| 项 | 孩子 | 成人 |
| --- | --- | --- |
| IPA | **不显示** | 显示，且高亮 issues 对应音素 |
| 分数 | 不显示数字，1–3 星 + 一句鼓励 | 0–100 环 + 分项 |
| 低分 | 不存在“低分”概念；`tier=.retry` 时文案“再来一次会更棒” | 显示红色“需加强” |
| 词级着色 | 只标“说对了/再试试”两色（绿/中性） | 四级色阶 |
| 语调曲线 | 隐藏 | 显示 |
| 按钮 | 主按钮 56pt、字 20pt；“下一句”带箭头动效 | 48pt |
| 示范音默认语速 | slow | normal |

## 4. 连读模式（Flow）

### 4.1 目标
连续朗读 N 句，**录完立刻下一句**，评分在后台完成，页面永不阻塞。

### 4.2 布局

```
┌────────────────────────────────┐
│ ‹ 连读模式            3 / 10    │
│ ● ● ● ◐ ○ ○ ○ ○ ○ ○            │  ← 每句状态点（灰/脉冲/绿/红）
│                                │
│ ┌────────────────────────────┐ │
│ │ I usually walk to school.  │ │
│ │ 我通常走路去学校。            │ │
│ └────────────────────────────┘ │
│        ┌──────────────┐        │
│        │   🎤 开始朗读  │        │
│        └──────────────┘        │
│  录完立刻进入下一句，不用等评分   │
│                                │
│  ── 已完成（可折叠）────────────  │
│  1. I usually walk…   78 ✅     │
│  2. My school is far… 评分中…   │
└────────────────────────────────┘
```

### 4.3 交互
- 开始前：选择数量（5/10）、来源（当前难度 / 错音本）、是否显示中文（默认显示）。
- 按下录音 → 停止 → **立即**：`POST /attempts/async` → 状态点变“评分中” → **自动切下一句**（不等待响应，上传在后台 Task 中）。
- 若上传本身失败（网络抖动）：该项标红，**不打断流程**，末尾统一“补录/重试”。
- 轮询：录音过程中每隔 2s 批量 `GET /attempts/status?ids=…`；全部终态后停止；90s 超时保留已完成。
- 顶部进度点实时反映：待录（灰）→ 上传中（脉冲）→ 评分中（蓝色脉冲）→ 完成（绿，成人显示分数）→ 失败（红）。
- 最后一句结束 → 汇总页：完成 n 句、评分成功 m、失败 k；成人显示逐句分数与平均分，孩子显示星星 + 鼓励；失败项提供“重试评分”（有 id，用 `/attempts/:id/retry`）与“补录”（无 id 时）。
- 中途退出：二次确认“还有 n 句没录，退出会保留已录音的评分”，退出后仍可在结果里看到已提交项（本地保存 attempt ids）。**【客户端自行实现】**

### 4.4 API

| 调用 | 说明 |
| --- | --- |
| `POST /attempts/async` | multipart，立即返回 `{id,status:"pending"}` |
| `GET /attempts/status?ids=a,b,c` | 批量轮询，≤10 个/批 |
| `POST /attempts/:id/retry` | 单项重评（不重录） |
| `POST /tts` | 每句示范音可预取下一句 |
| `GET /sentences?level=` | 组卷（客户端随机抽取 + 去重 + 错音本优先） |

### 4.5 状态

| 状态 | 表现 |
| --- | --- |
| 组卷中 | 骨架 + “正在准备 10 个句子” |
| 录音中 | 波形 + 计时；顶部进度点动画 |
| 后台评分 | 列表项“评分中”；不阻塞任何操作 |
| 部分失败 | 顶部黄条“2 句评分失败，查看”；点击定位 |
| 全部完成 | 汇总页 + 下一轮 |
| 离线 | 入口禁用，提示“连读需要连接服务器评分” |
| 语料不足 | 若可用句子 < 需求数，降级为实际数量并提示 |

### 4.6 儿童/成人差异
- 孩子：**过程完全不显示分数**，只显示进度点与“完成！”；汇总页给星星与“今天读完 10 句，真棒”；失败项文案“有 2 句没登记上，再读一次吧”。
- 成人：实时显示每句分数与平均分，可点击查看单句详情（复用跟读结果组件）。

```
│        ┌──────────────┐        │
│        │   🎤 按住说   │        │  ← 唯一输入方式
│        └──────────────┘        │
│        （正在思考… / 正在说话…）  │
└────────────────────────────────┘
```

### 5.3 交互（一轮 = 一次录音）
1. 进入：显示开场白（若 `POST /chat/sessions` 返回首轮消息/音频则直接播；**【待确认】** 是否返回开场）。
2. 点/按住麦克风球 → 立刻停止正在播放的 TTS → 录音（≤60s，≤30s 更符合对话节奏，建议 30s 上限）。
3. 停止 → `POST /chat/sessions/:id/turn`（multipart `audio`）→ 状态“正在思考…”（同时可展示“正在听…”→“正在想…”两段，由上传/等待阶段切换）。
4. 响应到达：追加助手气泡（文本）+ 落盘音频 → 自动播放（可在设置关闭）；播放时气泡高亮。
5. 播放中用户再次按麦克风：立即停止播放并开始录音（**打断优先**）。
6. 失败：气泡位置内联“没听清，再说一次”（`unsupported_audio`/空识别）或“服务器有点慢，重试”（超时）；**不重发旧音频**（对话有时序语义），改为重说。
7. 结束：本地退出并确认；无 `DELETE /chat/sessions/:id`（**【待确认】**），退出不删除服务端记录。

### 5.4 API

| 调用 | 说明 |
| --- | --- |
| `GET /chat/scenarios` | 场景列表（缓存 7 天） |
| `POST /chat/sessions` | `{scenario_id}` → 会话（返回 id + 可能首句） |
| `POST /chat/sessions/:id/turn` | multipart audio；返回文本 + 音频（形态**【待确认】**） |
| `POST /tts` | 助手消息重播/慢速（若 turn 已返回音频则用本地） |
| `POST /asr` | 仅当需要显示“我说了什么”时使用；**【待确认】** turn 是否已带 transcript |

### 5.5 状态

| 状态 | 表现 |
| --- | --- |
| 录音中 | 球体红点 + 波形 + 计时 |
| 上传/等待 | “正在听…”→“正在想…”（超过 8s 追加“网络有点慢”） |
| 播放中 | 气泡声波动画 + 点击可暂停 |
| 识别为空 | “我没听清，再说一次” |
| 服务不可用 | 顶部横幅 + 重试；保留对话历史可读 |
| 会话失效（404/401） | “这段对话已结束”，返回场景页 |
| 空态 | 无历史（新会话）→ 显示场景开场提示与例句 |

### 5.6 儿童/成人差异
- 孩子：**只有语音，无任何文字输入**（严格约束）；助手文本默认隐藏中文翻译，提供“听不懂？看中文”按钮（若返回中文）；麦克风球 96pt 常驻底部；播放速度默认 slow。
- 成人：助手文本 + 可选中英文对照；可长按气泡复制文本（M4）；录音上限 30s。
- 两者都**没有**键盘、没有 `TextField`、没有“发送”按钮。

### 6.1 列表页

```
┌────────────────────────────────┐
│ 我的故事            [＋ 新建]    │
│  [故事] [书页]                  │
│ ┌────────┬────────┐            │
│ │ 插画    │ 插画    │            │
│ │ 小熊...  │ 一次...  │            │
│ └────────┴────────┘            │
│ 空态：还没有故事，拍一张书页开始  │
└────────────────────────────────┘
```

- `GET /materials?kind=story|page`；卡片图 `GET /materials/:id/image`（带缓存）。
- 滑动删除/重命名：`POST /materials/:id/...`（具体路径**【待确认】**）；失败则回滚并提示。
- 离线：列表与已缓存图片可看，详情文本可读；创建/插画/复述禁用。

### 6.2 创建向导（4 步，可后退）

| 步骤 | 界面 | API |
| --- | --- | --- |
| 1 选来源 | 三个大按钮：拍照 / 相册 / 手动输入中文；拍照与相册用 `PhotosPicker` + 相机封装 | 无 |
| 2 校对文字 | OCR 文本可编辑（`TextEditor`）；显示 `warnings`（如“未检测到文字”）；“重新拍” | `POST /ocr`（multipart image） |
| 3 设定 | 难度 A1/A2/B1/B2/C1（默认 profile.cefrLevel）；开关“针对我的弱音素”（带 `/diagnosis` 的 weak_phonemes）；最多句数（可选） | `GET /diagnosis`（可选） |
| 4 生成 | 逐句列出英文 + 中文；`readability` 标签；可“换一版”；然后“生成插画”（可跳过） | `POST /story/rewrite` → `POST /story/:id/illustrate` |

细节：
- **HEIC**：先查 `/health` 的 `voice.capabilities.heic`；为 `true` 时可直接上传原图（体积大，需进度条）；否则客户端转 JPEG（最长边 2048，质量 0.8）再传。
- OCR 结果为空：不进入下一步，提示“没认出文字，试试光线亮一点/换一张”。
- 改写等待：10–30s 级操作，显示“正在把故事变简单…” + 可取消；超时用 `provider_timeout` 文案。
- 插画等待：可能 >20s，显示进度动画 + “可以稍后在看故事里查看”（**若服务端异步生成**则轮询/重进刷新；**【待确认】** 是同步返回 URL 还是异步）。
- 生成成功 → 跳转详情；失败 → 保留已生成的英文文本（不要丢），可单独重试插画。

### 6.3 详情 / 复述

```
┌────────────────────────────────┐
│ ‹ 小熊去上学              ⋯     │
│ ┌────────────────────────────┐ │
│ │         （插画）            │ │
│ └────────────────────────────┘ │
│ 1. The bear goes to school. ▶  │
│ 2. He meets a new friend.  ▶   │
│    中文翻译（可折叠）            │
│                                │
│  [🎤 复述这个故事]              │
│  ── 复述结果 ──                 │
│  覆盖 4/6 个要点  ⭕ 67%        │
│  ✅ 说到了：…                   │
│  ⬜ 还差：…                     │
│  反馈（中文/英文）               │
└────────────────────────────────┘
```

复述流程（两步，客户端编排）：
1. 录音 → `POST /asr`（`language=en`）拿 `transcript`；
2. `POST /story/retell {story_sentences, transcript, level}` → `coverage/covered_points/missing_points/feedback_zh/feedback_en`。
- `story_sentences` 从详情数据取（创建时本地保存 + 详情接口返回，**【待确认】** 是否由 `/materials/:id` 提供）。
- 复述录音上限 120s（故事更长），仍受 12MB 限制。
- 孩子：覆盖度用星星/进度条，不用百分比；反馈只显示中文。

| 调用 | 用途 |
| --- | --- |

## 7. 盲测

### 7.1 定位
“不看文本”检验真实听力与发音，两种模式互补：

| 模式 | 做什么 | 依赖 |
| --- | --- | --- |
| A 盲听选择 | 播放 TTS（隐藏文本）→ 四选一（中文意思） | 纯客户端 + `/tts` |
| B 盲跟读 | 播放 TTS 1–2 次（隐藏文本）→ 跟读 → 评分后揭晓原文 | `/attempts`（`mode=unscripted`） |

### 7.2 设置页
- 数量 5 / 10；来源：当前难度 / 错音本；模式 A 或 B（可都选，交替出题）。
- 开始按钮（大）。

### 7.3 进行页

```
┌────────────────────────────────┐
│ ‹ 盲测            2 / 5   ⏱     │
│        [🔊 再听一次]            │  ← 最多 3 次
│                                │
│  A:  ┌──────┐┌──────┐          │
│      │ 猫…  ││ 狗…  │          │
│      └──────┘└──────┘          │
│      ┌──────┐┌──────┐          │
│      │ 鸟…  ││ 鱼…  │          │
│      └──────┘└──────┘          │
│                                │
│  B:  [🎤 跟读] → 评分后揭晓原文    │
│                                │
│  （答后）原文 + 中文 + [下一题]   │
└────────────────────────────────┘
```

- 选项由客户端从同难度语料随机取 3 个干扰项（中文翻译）+ 正确项打乱。
- 答错（A）不立刻给红色大叉：中性提示 + 显示原文与中文 + “再听一次”。
- B 模式提交后待评分，期间显示“听听你说的像不像”；揭晓后高亮漏读词。
- 全部结束：得分（成人）/ 星星（孩子）、错题清单、“把错句加入练习”。
- 退出确认；中途退出不保存进度（M4 可做断点续测）。

### 7.4 API
`GET /sentences?level=`、`POST /tts`（每题预取下一题）、`POST /attempts`（B 模式，`mode=unscripted`）。

### 7.5 状态
| 状态 | 表现 |
| --- | --- |
| 音频未就绪 | 播放按钮转圈，禁止答题（避免瞎猜） |
| TTS 失败 | “这道题听不了，跳过” |
| B 评分失败 | 允许“跳过此题”，不阻塞整套 |
| 离线 | 仅 A 模式且 TTS 已缓存时可玩；B 模式入口禁用 |
| 语料不足 4 句 | 隐藏 A 模式（无法凑干扰项） |

## 11. 修改密码

| 对象 | 能力 | 现状 |
| --- | --- | --- |
| 孩子账号 | 家长在“家庭成员”里重置 | **【已实现·后端现有】** `POST /family/members/:id/password` |
| 家长自己 | 修改自己的密码 | **【待后端新增】** 无对应接口；当前只能由 NAS 侧管理员改 |

因此本期的“修改密码”页有两个入口、两种形态：

1. **孩子（由家长操作）**：入口在 家长面板 → 成员 → 重置密码。表单：新密码 + 确认；提交后提示“已更新，孩子下次登录用新密码”。不要求旧密码（接口如此）。
2. **家长自己**：入口在 设置 → 修改密码。**后端就绪前**该入口显示说明页：“暂不支持在 App 内修改家长密码，请在 NAS 上操作”，并给出复制命令/说明；后端提供 `POST /auth/password {old,new}` 后再替换为表单（加入 open-questions Q6）。

校验与安全：
- 前端校验：≥8 位、两次一致、不与邮箱相同；**最终以服务端策略为准**；
- 提交中禁用；成功后**强制重新登录**（会话可能已失效，统一按最保守处理）；
- 错误：`bad_request` → “密码不符合要求（至少 8 位）”；401 → “旧密码不正确”（待后端支持后）。

- 提交：`POST /suggestions`；成功 Toast + 清空 + 列表顶部插入新条目；失败保留内容 + 内联错误。
- 列表：状态标签（待处理/已处理，**【待确认】** 状态枚举）、时间、内容。
- 离线：保存草稿，进页面时提示“有未提交的草稿”。
- 孩子不可见该入口（API 仅家长）。

## 13. 通用状态组件（全 App 复用）

| 组件 | 使用场景 | 关键点 |
| --- | --- | --- |
| `LoadingSkeleton` | 列表/详情首屏 | 形状与真实内容一致，避免布局跳动 |
| `ErrorStateView` | 全页失败 | 图标 + 一句话 + 重试 + “检查服务器” |
| `InlineError` | 表单/提交失败 | 红字 + 可选“重试”按钮，不遮挡内容 |
| `OfflineBanner` | 顶部常驻 | 三态：无网络 / 连不上 NAS / 仅蜂窝 |
| `PermissionCard` | 麦克风/相机被拒 | 说明 + 去设置 + 兜底路径 |
| `EmptyStateView` | 空列表 | 插画/图标 + 下一步动作（必须可操作） |
| `SessionExpiredSheet` | 401 | 唯一按钮“重新登录” |
| `ScoringIndicator` | 评分中 | 脉冲 + “正在听你的发音”，不显示假进度 |
| `Toast` | 轻量成功反馈 | 2s 自动消失，不阻断 |

## 14. 儿童 vs 成人 总表

| 维度 | 孩子（`role=child`） | 成人/家长（`role=parent`） |
| --- | --- | --- |
| Tab | 练习/对话/故事/我的（4） | 家长/练习/对话/故事/我的（5） |
| IPA | 不显示 | 显示 |
| 分数 | 不显示数字；1–3 星 + 鼓励语 | 0–100 + 分项 + 曲线 |
| 低分 | 不出现“低分/失败”概念 | 显示“需加强” |
| 按钮 | 56pt 高，主按钮占满宽度 | 48pt，可并排 |
| 字号 | Body 20pt（×1.15） | Body 17pt |
| 文案 | 短句、口语、鼓励、无术语 | 可用“音素/掌握度/覆盖率” |
| 难度 | 锁定账号等级 | 自由切换 |
| 服务器地址 | 不可改 | 可改 |
| 家长数据 | 不可见 | 可见 |
| 设置项 | 简化（无缓存明细/无诊断信息） | 完整 |
| 对话 | 仅语音、大麦克风球 | 仅语音（产品约束同样适用） |
| 错误 | 中性提示 + 下一步动作 | 具体原因 + 重试 |
| 反馈语言 | 中文为主，英文仅示例句 | 中英对照 |
