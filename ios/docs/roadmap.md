# 路线图 · M0 → M4

> 每个里程碑都是**可演示的纵向切片**（能登录、能录、能看到结果），不是"先写完全部网络层"。
> 产能假设：1 名 iOS 开发 + 1 名后端（仅配合确认契约），人日为**估算**，不含等待后端答复的时间。
> 标注：【已实现·后端现有】/【待后端新增】/【客户端自行实现】/【待确认】。

---

## 0. 里程碑总览

| 里程碑 | 主题 | 核心能力 | 预估 | 阻塞项 |
| --- | --- | --- | --- | --- |
| **M0** | 骨架跑通 | **Bearer 登录/刷新/吊销 + TestFlight 内测通道** + 单句跟读（录音→评分→结果） | 6–8 人日 | 后端 token 三接口（B17）、Apple Developer 账号 |
| **M1** | 连续与对话 | 连读异步队列 + 语音对话（ASR→turn→TTS + pron 轮询） | 6–8 人日 | B2 异步状态机、B9 attempts 字段 |
| **M2** | 故事 | OCR → 改写 → 插画 → 复述 → 作品集 | 8–10 人日 | B3 `rewrite` 返回、B4 `materials` 删除、B5 `illustrate` 同步性 |
| **M3** | 评估与家长 | 盲测 + 诊断/错音本 + 家长面板/成员/建议 | 8–10 人日 | B6 `summary` 字段、B7 `suggestions` 字段、B8 家长自改密码 |

## 1. 全局 Definition of Done

任何功能标记"完成"前必须满足：

- [ ] 真机（非模拟器）验证主链路，且至少一台小屏设备（iPhone SE 尺寸）不截断；
- [ ] 四种状态齐全：loading / empty / error / offline，且都有截图或录屏；
- [ ] 错误文案走 `ErrorMapper`，孩子/成人两套都验证；
- [ ] 组件在成人 + 孩子两种 `RoleCapabilities` 下渲染正常；
- [ ] 无新增第三方运行时依赖（或已附 ADR）；
- [ ] 无 `print`、无待办 `TODO` 遗留在主分支（用 `#warning` 或 issue 跟踪）；
- [ ] 相关单测通过，覆盖率不强制但核心纯函数（映射/解析/状态机）必须有；
- [ ] 文档同步：`screens.md` 对应小节与实现一致。

## 2. M0 · 骨架（登录 + 跟读）

### 2.1 范围

| 包含 | 不包含 |
| --- | --- |
| Xcode 工程、目录、CI 脚本骨架 | 连读、对话、故事、盲测、家长面板 |
| `AppRoot` token 恢复、角色化 Tab（先只做“练习/我的”两个占位） | 动画打磨、深色模式 |
| 登录 / 刷新 / 吊销 / 401 单飞刷新 / Keychain 持久化 | 离线队列 |
| **TestFlight 内部测试通道**（构建上传、测试组、90 天续期记录） | 外部测试 / App Store 上架 |
| `Core/Networking`：Endpoint、APIClient、Multipart、错误映射、重试、Bearer 注入 | 离线队列 |
| `Core/Audio`：权限、录音、播放、互斥、电平 | 后台播放、蓝牙专项优化 |
| 语料列表（A1–B2）+ 难度切换 + 缓存快照 | 分页（视后端而定） |
| 跟读页：示范音 → 录音 → `/attempts` 同步评分 → 结果 | 语调曲线（成人可先只显示分数与词级） |
| 孩子模式：无 IPA、无数字分、大按钮 | 星星动画 |
| 设计令牌 v1 + 6 个基础组件 | 全量组件库 |

### 2.2 交付物
- 可运行 App（真机，iOS 26）+ **TestFlight 内部测试包**（≤100 名内部测试员，无需 Beta 审核）；
- `ErrorMapper` 全 code 单测 + 刷新/Keychain 单测；
- 录音参数定稿：**16kHz / 单声道 / AAC 65kbps**（写入 `audio.md`，不做 A/B 分支）；
- token 三端点实测结论（写入 ADR-0003 的“验证记录”）。

### 2.3 验收标准（逐条可勾）
1. 新装 App → 登录 → 杀进程 → 重开，**无需重新登录**（Keychain token 生效；refresh 未过期）。
2. access 过期后任一业务请求 401 → **单飞刷新一次→自动重放**，用户无感；刷新被拒才回登录页。
3. 任选 A1 句子：播放示范 → 录音 → 看到分数与词级结果，端到端 ≤8s（局域网，含上传+评分）。
4. 录音时正在播放的示范音**立即停止**；播放时点录音不会叠音。
5. 拒绝麦克风 → 出现引导卡 → 去设置开启 → 返回后可直接录音（无需重启）。
6. 断网后进入列表：显示缓存 + 离线横幅；录音后提示"需要服务器才能评分"。
7. 服务端返回 `provider_unavailable` 时显示对应文案与"重试"，不出现原始英文错误。
8. 孩子账号：结果页**无 IPA、无数字分数、无红色低分**，按钮高度 ≥56pt。
9. 退出登录：`/auth/revoke` 返回 204，本地 token 清空；旧 refresh 再刷新返回 401。
10. 单元测试：`ErrorMapper`、`MultipartBody`、`ScorePresenter`、`TokenRefresher`（并发 401）全绿。
11. 冷启动到首屏 ≤1.5s（iPhone 12 及以后，本地缓存已存在）。
12. TestFlight：内部测试员能从 TestFlight 安装并完成上述主链路；记录构建上传日期与 90 天到期日。

### 2.4 风险

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| 后端 token 三接口未就绪 | M0 无法收尾 | 后端 P0 优先实现（B17）；客户端可先用 `URLProtocol` 桩推进网络层 |
| refresh 一次性轮换 + 并发 401 | 并发刷新互相作废，随机掉登录 | 强制单飞刷新；单测覆盖并发 3 个 401 只发 1 次 refresh |
| Keychain 写入失败/重装行为差异 | 重启掉登录 | 记录 Keychain 错误码；启动时校验 `/auth/me`；不把 Keychain 当安装标识 |
| 同步评分耗时 >8s | 跟读体验差 | 实测后切 `async` + 轮询（状态机在 M1 就绪，可提前） |
| 服务端解码 AAC 参数异常 | 上传失败 | 统一 16k/65k；真机复核文件参数与服务端错误码，**不预留码率/采样率兜底分支** |
| 测试设备未升级 iOS 26 | 无法安装 | M0 前确认测试设备系统版本（Q2 已决） |
| TestFlight 构建 90 天过期 | 家长侧突然打不开 | 到期前 2 周重新上传；记录到期日（README §6.6） |

## 3. M1 · 连读 + 对话

### 3.1 范围

| 包含 | 不包含 |
| --- | --- |
| 连读：组卷、边录边传、`/attempts/async`、批量轮询、失败重试、汇总 | 断点续测（M4） |
| 对话：场景列表、建会话、逐轮录音（`/asr` → `/turn` → `/tts`）、pron 轮询、自动播放、打断 | 文字输入（产品禁止） |
| TTS 本地缓存 + 下一句预取 | 对话历史列表（无 API） |
| 后台播放（`UIBackgroundModes=audio`）+ 锁屏控制（可选） | 推送 |
| 轮询状态机单测（全成功/部分超时/页面退出） | 家长相关 |

### 3.2 验收标准
1. 连读 10 句：每句录完**立即**进入下一句，页面无 >200ms 的卡顿；评分在后台完成，进度点状态正确。
2. 全部录完后 ≤3s 内汇总页出现；若某句 90s 仍未完成，标记"稍后查看"且不阻塞汇总。
3. 中途杀进程再进入：已提交的 attempt 结果仍可查看（本地持久化 ids + 拉取）。
4. 对话场景：选场景 → 说一句 → `/asr` → `/turn`（text 必填）→ `/tts` → 听到回复音频 + 看到文本，单轮 ≤8s（局域网，三次调用叠加）。
5. 对话播放中按麦克风：播放立即停止并开始录音，不产生"录到自己的 TTS"。
6. 对话页**没有**键盘/文本框（UI 测试断言无 `TextField`）。
7. 同一条 TTS 第二次播放命中缓存，起播 ≤300ms。
8. 锁屏后 TTS 继续播放；回前台 UI 状态一致。
9. 轮询任务在页面退出/后台时正确取消或暂停，无后台耗电异常（Instruments 验证 5 分钟无持续网络）。
10. 对话发音：每轮结束后轮询 `GET /sessions/:id/messages`，`pron` 在 ≤15s 内补到用户消息；超时显示“稍后查看”，不阻塞下一轮；`GET /sessions/:id` 不被用来取 `pron`。

### 3.3 风险
- 三步链路（ASR→turn→TTS）时延叠加 → 每步都要有明确状态文案；开场白在进入页面时预合成 TTS，不等用户点；
- 生成本身慢（LLM+TTS）→ 需要"思考中"的耐心设计，避免用户误以为卡死；
- 连读的并发上传：限制**同时最多 2 个**上传，避免局域网 NAS 排队导致全部超时；
- 对话满 6 轮服务端自动 `done`，之后 turn 返回 409 `session_closed` → 客户端要提前提示并在结束时回场景页。

## 4. M2 · 故事模式 + 插画

### 4.1 范围
- 拍照 / 相册 / 手输中文；
- HEIC 处理（按 `/health` 能力降级为 JPEG）；
- OCR 校对（可编辑、`warnings` 展示）；
- 改写（难度、弱音素、最多句数、readability）；
- 插画（进度、失败重试、跳过）；
- 作品集（列表/详情/删除/重命名）；
- 复述：录音 → `/asr` → `/story/retell` → 覆盖度与反馈；
- 图片缓存（LRU 100MB）。

### 4.2 验收标准
1. 拍一张中文书页 → 10–30s 内拿到英文故事（含中文对照），可逐句播放。
2. HEIC 原图上传在 `capabilities.heic=false` 时自动转 JPEG 且总体积 <5MB。
3. OCR 无文字时给出可操作提示，不进入下一步，不丢已拍图片。
4. 改写失败可重试；重试不会重复创建两条作品（幂等/去重）。
5. 插画失败时文字成果保留，可单独重试插画。
6. 复述：录 30s 英文 → 覆盖度与 missing points 正确展示；`asr` 空结果时提示"再说一次"而非崩溃。
7. 作品集离线可读（文本 + 已缓存图片），操作按钮禁用并解释。
8. 图片缓存超过 100MB 时按 LRU 清理，不删当前打开的故事。

### 4.3 风险
- `/story/:id/illustrate` 若为同步生成且 >30s，需转"后台任务 + 轮询/刷新"模式（B5）；
- 任意书页 OCR 的内容安全与版权（Q12）——先限定"家庭自用、不上传公网"；
- `story_sentences` 来源不明确（B3），客户端需在创建时本地持久化，避免依赖猜测。

## 5. M3 · 盲测 / 诊断 / 家长面板

### 5.1 范围
- 盲测 A（盲听四选一，纯客户端）与 B（盲跟读 + 揭晓）；
- 成长：`/diagnosis`、`/review`、音素详情、本地近 7 天趋势；
- 家长：汇总、成员列表/新建/重置密码、建议箱；
- 修改密码：孩子走家长重置；家长自己按 Q6 结论实现或显示说明页；
- 服务器体检页（`/health` 能力矩阵）。

### 5.2 验收标准
1. 盲测 A：5 题全部离线可玩（TTS 已缓存时）；答错不出现大红叉，显示原文与"再听一次"。
2. 盲测 B：评分后揭晓原文，高亮漏读词；单题失败可跳过，不影响整套。
3. 孩子进入成长页：**无 IPA、无百分比**，建议文案可读；成人两种都有。
4. 错音本条目可直接跳转跟读并完成一次练习。
5. 家长面板：汇总数据缺失字段时**不崩溃、不显示空白卡**（容错渲染单测覆盖）。
6. 新建孩子账号 → 用新账号登录 → CEFR 等级正确带入练习页。
7. 家长重置密码后，旧密码登录失败、新密码成功。
8. 孩子账号访问 `/parent/summary` 得到 403 时显示无权限页，不泄露任何数据。
9. 建议提交成功后在列表可见；离线时草稿保留。

### 5.3 风险
- `/parent/summary` 字段未知（B6）→ 先只做"能展示就展示"的骨架，字段确认后再排布局；
- 家长看"某个孩子"的详情缺少 API（可能是新需求）→ 本期只做汇总，按开放问题排期；
- 盲测 B 依赖 `/attempts` 的 `unscripted` 语义，需确认 `reference_text` 是否必填（B9）。

## 6. M4 · 打磨

### 6.1 候选范围（按优先级）
1. **离线增强**：录音本地队列，联网后补交评分（需明确"补交"语义：attempt 时间戳以客户端为准还是服务端）；
2. **通知/提醒**：本地通知"今天还没练"；APNs 需 NAS 出网（Q7）；
3. **Widget**：今日一句 + 连续天数（数据来自本地缓存，不直接打 API）；
4. **iPad/横屏**：分栏布局、大屏排版（Q8）；
5. **深色模式**：跟随系统（Web 无深色，需要设计出图）；
6. **无障碍**：VoiceOver 全流程、AX3 字号、对比度复核；
7. **家长查看孩子录音**：需【待后端新增】授权接口；
8. **性能**：启动、列表滚动、图片解码降采样、包体积；
9. **TestFlight Beta 运维**：90 天到期重传、内部测试员管理、TestFlight 反馈收集（分发通道在 M0 打通，见 README §6.6）。

### 6.2 验收标准（按项）
- 离线补交：飞行模式下录 3 句 → 恢复网络 → 自动补交并在历史中可见（若实现）；
- Widget：主屏显示今日句，点击直达跟读；
- iPad：分栏下不出现拉伸变形的卡片，键盘不遮挡（如有输入）；
- 无障碍：VoiceOver 可完成"登录→跟读→听结果"全链路，无未标注按钮；
- TestFlight：至少一次完整的"过期构建 → 重新上传 → 内测员收到更新"演练，记录耗时与步骤；
- 崩溃率与卡顿：无新增 crash，滚动丢帧 <1%。

## 8. 明确不做（本期范围外）

| 项 | 原因 |
| --- | --- |
| 后端其他改动（Bearer token 三接口属已确认的 P0 前置，不在“不做”范围） | 任务前提：后端已完成 Web 端；移动端只新增认证端点 |
| 文字对话输入 | 产品约束（对话只有语音） |
| 客户端实时语音流（WebSocket/流式） | 服务端无此接口；现有 HTTP 轮次已够用 |
| 本地 ASR/评测 | 服务端能力，客户端不做 |
| 多语言 UI（英文界面） | Q5 未定 |
| 账号注册 / 找回密码 | 无 API；账号由家长创建 |
| 数据导出 | 无 API |
| 社交/排行榜 | 与家庭场景不符，且无数据 |
| App Store 上架 / 免费账号自签 | 分发方式已定为 TestFlight 内部测试（README §6.6） |
