# 设计系统 · Design Tokens 与组件规范

> 目标：与 Web 端视觉语言一致，同时满足 HarmonyOS 的尺寸/密度/无障碍要求。
> 本文的 token 是**客户端唯一来源**；页面禁止写死颜色/圆角/字号。
> 颜色/圆角**以仓库根 `docs/design-tokens.md` 为准**（从 Web 实际 CSS 提取：`#F5F7FF` / `#5B5BD6`）。本文早期用的是近似值，已同步更正；与 Web 的其余差异见第 1.3 节。

### 1.2 语义使用规则

- **分数颜色**：
  - ≥85：`ec_good`；
  - 70–84：`ec_info`；
  - 60–69：`ec_warn`；
  - <60：`ec_bad`。
  - 儿童模式 <60 **不显示数字**，也不使用红色；用 `ec_warn` + 鼓励语 + 星星。
- **不要只靠颜色**：分数同时用数字/文字（成人）或星星/文案（儿童）；色盲用户仍能理解。
- **背景/文字配对**：小字号文字用 `*_text` 变体；`ec_good/ec_warn/ec_bad` 只用于图形、描边、大数字。
- **主色面积**：一屏最多一个主色实心按钮；其他用 tonal/ghost，避免“全是紫色按钮”。

### 1.3 与现有 Web 的差异（需要对齐）

现有 Web `web/src/app/globals.css` 实际值：

| 项 | Web 现值 | 本文值 | 差异 |
|---|---|---|---|
| 背景 | `#F5F7FF` | `#F5F7FF` | ✅ 已对齐（早期近似值 `#F8F9FF` 已废）|
| 主色 | `#5B5BD6` | `#5B5BD6` | ✅ 已对齐（早期近似值 `#4F46E5` 已废）|
| 主色浅底 | `#ECEBFF` | `#EEF0FF` | 极接近 |
| 卡片圆角 | `1.25rem`（20px） | 16px（卡片） | 本文更紧凑 |
| 阴影 | `0 8px 24px rgba(27,31,59,0.06)` | 同 | 一致 |

**建议**：M0 由 Web 侧补一份共享 token（纯前端改动，不动后端），或把本文值改成 Web 现值；在拍板前，**客户端以本文为准**，验收时做一次并排视觉对比。不要让两端各自“差不多”。

## 2. 字体与排版

### 2.1 字体

- 系统字体：HarmonyOS Sans（跟随系统），不引入第三方字体（体积/授权/一致性）。
- 中文/英文混排：英文用系统默认西文，数字用 **tabular numerals**（分数、计时、统计）。
- 字号单位 **fp**，尊重系统字体缩放；布局用 `constraintSize`/`Flex` 防溢出，不写死高度。

### 2.2 字号阶梯

| Token | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| `display` | 32/40 | Bold | 首页大标题、分数（成人） |
| `h1` | 28/36 | Bold | 页面标题 |
| `h2` | 24/32 | Bold | 卡片标题 |
| `h3` | 20/28 | SemiBold | 分区标题 |
| `body` | 16/24 | Regular | 正文 |
| `body_strong` | 16/24 | Medium | 重点正文 |
| `caption` | 13/18 | Regular | 说明/时间 |
| `micro` | 11/16 | Regular | 角标（尽量少用） |
| `child_body` | 19/28 | Regular | 儿童正文 |
| `child_h1` | 30/38 | Bold | 儿童页面标题 |
| `child_button` | 19/24 | SemiBold | 儿童按钮 |

### 2.3 排版规则

- 正文最大宽度：手机 100%，平板 720vp；超过用两栏。
- 句子卡：英文 22–24fp、行高 1.5；中文翻译 14–16fp、`ec_muted`。
- 分数数字：使用等宽数字（系统字体支持 tabular numerals 时）；不要用艺术字体。
- 标题不超过 2 行；超出省略，完整内容放详情。
- 儿童模式全局字号 ×1.15（通过 `child_*` token，不做运行时缩放，避免布局错乱）。

## 3. 间距 / 圆角 / 阴影

### 3.1 间距（4 的倍数）

| Token | 值 | 用途 |
|---|---|---|
| `space_1` | 4vp | 图标与文字 |
| `space_2` | 8vp | 紧凑元素 |
| `space_3` | 12vp | 卡片内边距（小） |
| `space_4` | 16vp | 页面左右边距/卡片内边距 |
| `space_5` | 20vp | 卡片间距 |
| `space_6` | 24vp | 区块间距 |
| `space_8` | 32vp | 大区块 |
| `space_10` | 40vp | 页面顶部 |
| `space_12` | 48vp | 空状态留白 |

页面左右安全边距：手机 16vp；平板 24vp；儿童 20vp。

### 3.2 圆角

| Token | 值 | 用途 |
|---|---|---|
| `radius_sm` | 8vp | 小标签/输入框内元素 |
| `radius_md` | 14vp | 按钮/输入框（Web `0.9rem`） |
| `radius_lg` | 20vp | 卡片（Web `1.25rem`） |
| `radius_xl` | 28vp | 大容器/弹层（Web `1.75rem`） |
| `radius_pill` | 999vp | 胶囊/头像 |

### 3.3 阴影

| Token | 值 | 用途 |
|---|---|---|
| `shadow_card` | `0 8 24 rgba(27,31,59,0.06)` | 卡片 |
| `shadow_raised` | `0 12 32 rgba(79,70,229,0.12)` | 主按钮/浮层 |
| `shadow_sheet` | `0 -8 32 rgba(27,31,59,0.10)` | 底部弹层 |

HarmonyOS 用 `.shadow({ radius, color, offsetX, offsetY })` 近似；不要叠 3 层以上阴影。

## 4. 按钮层级

### 4.1 类型

| 类型 | 外观 | 用途 | 一屏数量 |
|---|---|---|---|
| Primary | `ec_primary` 实心 + 白字 | 页面唯一主操作（开始说/提交/保存） | ≤1 |
| Tonal | `ec_primary_soft` 底 + `ec_primary` 字 | 次要操作（听示范/换一句） | 1–2 |
| Ghost | 白底 + `ec_border` 描边 + `ec_ink` | 第三级（取消/返回/更多） | 不限 |
| Danger | `ec_bad_bg` 底 + `ec_bad_text` 字 | 删除/退出/重置 | 少见 |
| Text | 无背景，主色文字 | 链接式操作（查看全部） | 不限 |

### 4.2 尺寸

| 尺寸 | 高度 | 圆角 | 字号 | 用途 |
|---|---|---|---|---|
| `sm` | 36vp | 10vp | 14fp | 标签/表格内 |
| `md` | 48vp | 12vp | 16fp | 默认 |
| `lg` | 56vp | 16vp | 17fp | 主 CTA |
| `child` | **60vp** | 20vp | 19fp | 儿童所有可点按钮 |

最小点击区域 **48×48vp**（儿童 56×56vp）；图标按钮也要满足，视觉小但热区大。

### 4.3 状态

| 状态 | 表现 |
|---|---|
| default | 如上 |
| pressed | 缩放 0.97 + 亮度 0.96，120ms |
| disabled | 透明度 0.45，不可点；仍显示原因（如“今天的时长用完了”） |
| loading | 左侧 16vp  spinner + 文案“登录中…”；禁用重复点击 |
| focus | 2vp `ec_focus` 外环（键盘/无障碍） |

### 4.4 录音按钮（特殊）

- 形状：圆形 72vp（儿童 88vp），主色/红色渐变；中心麦克风图标。
- 状态：idle（麦克风）/ preparing（波纹+“准备中”）/ recording（红色脉冲+计时）/ disabled。
- 录音中显示“说完啦 0:03”，点击停止；取消按钮在旁侧（`ec_bad_text` 文字按钮）。
- 不要用“长按录音”与“点击开始/停止”混用；全局统一一种（建议点击开始/停止，儿童更容易）。

### 5.1 图表规范

- 用 ArkUI `Canvas` 或 `Polyline`/`Path` 绘制，不引入图表库。
- 坐标轴不画网格（低认知负担）；只画 0/50/100 三条淡线。
- 分数颜色遵循 1.2；线条/柱子之外再加文字标签。
- 儿童不显示 F0 双曲线/雷达；用“星星/表情 + 文字”。
- 空数据不画 0 分图；显示 `EmptyState`。

## 6. 图标与插画

- 功能图标：系统 `SymbolGlyph`（HarmonyOS Symbol），统一 24vp 线性；选中态可用填充。
- 情绪/鼓励：Emoji（🌟🎉💪🌱🐢🐇），只用于文案，不承担关键信息。
- 空状态插画：优先用简单几何/Emoji，不引入第三方插画包；后续可加 3–5 张品牌插画（webp，≤100KB）。
- 不在按钮里混用“Emoji + Symbol”两种风格；一个按钮最多一个图标。

## 7. 动效

| 场景 | 时长 | 曲线 |
|---|---|---|
| 按钮按下 | 120ms | ease-out |
| 卡片出现 | 200ms | ease-out，透明度 0→1 + 位移 8vp |
| 分数出现 | 300ms | spring/scale 0.9→1 |
| 录音脉冲 | 1.4s 循环 | ease-in-out |
| 页面转场 | 250ms | 系统默认 |

- 尊重“减少动态效果”系统设置；关闭循环脉冲/弹跳。
- 不用粒子/烟花/全屏彩带（儿童容易过度兴奋，也增加性能负担）。
- 加载动画只用 skeleton 或小 spinner，不用全屏 loading 动画。

## 8. 响应式与平板

| 断点 | 宽度 | 布局 |
|---|---|---|
| Compact | <600vp | 单列；底部 tab |
| Medium | 600–839vp | 单列加宽；练习页可左右分栏（句子/结果） |
| Expanded | ≥840vp | 双栏；侧边 NavigationRail；家长面板 2 列 |

- 内容最大宽度 960vp，居中；两侧留白，不拉伸成“大字号网页”。
- 平板练习页：左侧语料列表 320vp，右侧句子+录音+结果；手机用底部抽屉选句。
- 横屏：录音按钮仍可见；结果区可滚动；不强制锁定方向（MVP 可锁竖屏，待拍板）。
- 儿童平板：按钮不因屏幕大而无限放大；最大 72vp 高。

## 9. 深色模式：取舍

### 9.1 结论

**MVP（M0–M3）只做浅色**，M4 再评估深色。原因：

- 现有 Web 只有浅色；两端同时做深色会拉长联调。
- 分数语义色（红/绿/黄）在深色底需要重新调对比度，不能简单反转。
- 儿童夜间使用场景可用系统“护眼/深色”缓解，但产品未要求。

### 9.2 工程准备（现在就要做）

- 所有颜色走 `$r('app.color.*')`，不写 `#hex`。
- 阴影/遮罩也 token 化；深色下阴影通常改为描边/更深的表面色。
- 图片/插画用透明底或双套资源；不要烘焙浅色背景。
- 在 `resources/dark/element/color.json` 预留同名 token（M4 填值）。

### 9.3 深色草案（M4 评审用，未验证）

| Token | 深色草案 |
|---|---|
| `ec_bg` | `#0F1220` |

| `ec_surface_alt` | `#1F2340` |
| `ec_ink` | `#F2F3FA` |
| `ec_muted` | `#A7ADC9` |
| `ec_primary` | `#8B87F5` |
| `ec_primary_soft` | `#242347` |
| `ec_border` | `#2A2E4A` |
| `ec_good` | `#4ADE80` |
| `ec_warn` | `#FBBF24` |

> 深色下的对比度、图表可读性、儿童模式都必须重新走查；不要直接复制浅色语义。

## 10. 无障碍

- 对比度：正文 ≥4.5:1；大字号 ≥3:1；主按钮白字 ≥4.5:1。
- 点击区域 ≥48vp（儿童 ≥56vp）。
- 图标按钮必须有 `accessibilityText`；分数环/图表提供文字摘要。
- 不只用颜色编码：分数配数字/文字；错误配图标+文案。
- 支持系统字体放大到 1.3×；关键按钮不被挤出屏幕。
- 录音/播放状态用文字+图标+颜色三重表达，方便听障/色觉障碍用户。
- 动效可关闭；不自动播放声音（除用户手势触发的“跟我读”）。

---

## 11. 文案语气

- 成人：简洁、具体、可执行。“录音已保存，稍后可重试评测。”
- 儿童：短句、鼓励、不否定。“这次差一点点，再来一次会更好 💪”
- 不出现：“错误”“失败”“你读错了”“0 分”“不及格”。
- 不出现技术词：HTTP、token、provider、IPA、API。
- 家长：可以具体，但避免制造焦虑；用“建议先练这两个音”而不是“孩子发音很差”。

## 12. 设计验收清单

- [ ] 页面无硬编码颜色/圆角/字号（grep `#`/`fontSize(` 抽查）。
- [ ] 一屏最多一个 Primary 实心按钮。
- [ ] 所有按钮 ≥48vp（儿童 ≥56vp），录音按钮 ≥72vp。
- [ ] 分数颜色符合 1.2；儿童 <60 无数字/无红色。
- [ ] 空态/错误态/加载态均有设计，不是临时文本。
- [ ] 深色资源文件存在但未启用；浅色下无“深色残留”。
- [ ] 平板 840vp 下无横向滚动/内容拉伸。
- [ ] 系统字体放大 1.3× 后无截断。
- [ ] 图标/Emoji 不混排；按钮文案不超过 8 个汉字。
