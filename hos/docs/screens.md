# 页面设计 · 12 个核心界面

> 路由名见 [architecture.md](architecture.md) 第 4 节。
> 所有页面共用：`PageScaffold`（安全区/标题/返回）、`ErrorBanner`、`EmptyState`、`LoadingSkeleton`、`ChildModeFrame`。
> 本文中的“分数”均指服务端 `scores.pron` / 子项；儿童模式有额外的**不显示低分**规则，见第 0 节。

---

## 0. 全局规则：儿童 vs 成人

| 维度 | 儿童（`isChild=true`） | 成人/家长 |
|---|---|---|
| IPA | **绝不显示**（音素符号、`/θ/`、nbest 都不渲染） | 显示音素明细、口型提示 |
| 低分 | **不显示 <60 的数字**；用“再来一次会更好 💪”+ 星星 | 显示完整分数与红色/橙色 |
| 总分 | ≥60 才显示数字；<60 只显示鼓励语 | 0–100 数字 + 颜色 |
| 子项 | 只显示“说得准不准/顺不顺/有没有漏词”，低分用“再练练” | 准确度/流利度/完整度/韵律 + 数值 |
| 按钮 | 最小 **56vp** 高，圆角 20–24vp | 48vp 高，圆角 12–16vp |
| 字号 | 正文 19fp，标题 24–28fp | 正文 16fp，标题 20–24fp |
| 导航 | 4 个 tab：跟读/连读/故事/我的 | 5 个：+ 家长面板 |
| TTS | 默认慢速 | 偏好（默认 normal） |
| 对话 | 强制 child_safe；不展示“自由话题” | 可由家长开关 |
| 图表 | 简化：柱状/星星；不显示 F0 双曲线 | 完整雷达/F0/趋势 |
| 错误 | 短句、口语、无 code | 可展示更多细节 + 重试 |

> 服务端已经对儿童剥离 IPA，但**不隐藏低分**。客户端必须在渲染层做“低分不显示数字”，不能只靠服务端。

## 1. 应用壳 / 首页

**路由**：`entry` 根 Navigation（无独立路由名）
**角色**：所有已登录用户
**目标**：让用户 3 秒内知道“今天练什么、还剩多少时间”。

### 结构

```text
┌─────────────────────────────────────┐
│ English Coach        🌐 NAS 已连接  │  ← 顶部：标题 + 网络/健康状态
│ 今天已练 12 / 20 分钟   [进度环]     │  ← 用量卡（儿童不可超）
├─────────────────────────────────────┤
│  🎤 跟读练习     一句话，马上开始 →  │
│  🔗 连读模式     5/10/15 句，一次读完 │
│  📖 我的故事     中文故事变英文绘本   │
│  💬 对话训练     和 AI 打个招呼       │
├─────────────────────────────────────┤
│  📒 错音本  ·  🔍 发音诊断  ·  ⚙️ 设置 │  ← 成人更多入口；儿童收进“我的”
├─────────────────────────────────────┤
│  [跟读] [连读] [故事] [我的]          │  ← 底部 tab
└─────────────────────────────────────┘
```

### 交互

- 启动：`BootstrapService` 读 token → `/auth/me`；成功进首页，失败按错误类型进登录/离线页。
- 顶部状态：`/api/health` 成功 → “NAS 已连接”；失败 → “连不上家庭 NAS” + 点击重试/网络说明。
- 用量：来自 `/auth/me` 的 `usage`；每次提交评测/对话后更新。
- 儿童：只保留 4 个 tab，首页卡片更大；不显示“家长面板”。
- 家长：多一个“👨‍👩‍👧 家长”tab；可看到孩子剩余时长。

### API

| 时机 | 接口 |
|---|---|
| 启动恢复 | `GET /auth/me` |
| 健康检查 | `GET /health` |
| 刷新用量 | `GET /auth/me` |

### 状态

| 状态 | 表现 |
|---|---|
| loading | 品牌 + 骨架卡片（不转圈超过 300ms 才显示） |
| error | 全屏“连不上家庭 NAS” + “重试” + “检查 Wi-Fi”；有缓存则提供“离线看看” |
| empty | 不适用 |
| 儿童 | 文案“今天想读哪一句呀？”；隐藏技术状态 |

## 2. 登录

**路由**：`login`
**角色**：未登录
**目标**：用家庭账号登录；明确“这是家庭 NAS，不是公网服务”。

### 结构

```text
┌─────────────────────────────────────┐
│            English Coach            │
│        家庭英语口语教练              │
│                                     │
│  邮箱                               │
│  [ dad@example.com              ]   │
│  密码                               │
│  [ ••••••••                 👁 ]   │
│                                     │
│  [        登 录        ]            │
│                                     │
│  🌐 家庭 NAS：已连接 / 连不上        │
│  忘记密码？让家长在家长面板重置       │
└─────────────────────────────────────┘
```

### 交互

- 输入：邮箱键盘、密码键盘；密码可见切换；错误时不抖动（避免儿童焦虑），用内联红字。
- 提交：按钮 loading“登录中…”，禁用重复点击。
- 成功：`POST /auth/login` → 保存 Cookie → `GET /auth/me` → 写 Session → `navStack.clear()` → 首页。
- 失败：
  - 401 → “邮箱或密码不正确”；
  - 400 → 服务端 message；
  - 网络 → “连不上家庭 NAS，请确认连着家里 Wi-Fi”；
  - 429 不适用。
- “忘记密码”：不提供自助找回（没有邮件服务）；文案引导家长重置；儿童版“让爸爸妈妈帮你看看”。
- 可选“记住邮箱”（Preferences，默认关）；**绝不记住密码**。
- 不提供注册：账号由家长在家长面板创建。

### API

| 时机 | 接口 |
|---|---|
| 登录 | `POST /auth/login` |
| 恢复 | `GET /auth/me` |
| 健康 | `GET /health`（可选） |

### 状态

| 状态 | 表现 |
|---|---|
| loading | 按钮内 loading；页面不整屏转圈 |
| error | 表单上方 `ErrorBanner`；保留输入 |
| empty | 不适用 |
| 儿童 | 大输入框、大按钮；文案更短；可显示头像/昵称（若家长提前告知） |

## 3. 跟读练习

**路由**：`practice?level=&focus=&sentenceId=`
**角色**：所有
**目标**：选一句 → 听示范 → 录一整句 → 看反馈 → 可重试。

### 结构

```text
┌─────────────────────────────────────┐
│ ← 跟读练习             A1 A2 B1 B2  │  ← 等级 segmented（C1 回退 B2）
├─────────────────────────────────────┤
│ “I think the weather is really...”  │  ← 句子卡（大字，可换行）
│ 我觉得今天天气真的很好。      [翻译] │
│ /θ/ /ð/ · 连读 · 日常               │  ← 成人显示 focus；儿童隐藏
│                                     │
│ [🔊 听示范]  [🎧 跟我读]            │
│                                     │
│        [ 🎤 开始说 ]                │  ← 主按钮
│                                     │
│ ── 结果 ─────────────────────────── │
│ [总分 82]  准确 85 流利 80 ...      │
│ 逐词条 / 音素 chips（成人）          │
│ 语调曲线（成人）                     │
│ 纠错卡片（最多 2 条）                │
│ [再读一遍] [重试评测] [下一句]        │
└─────────────────────────────────────┘
```

### 交互

1. 进入：加载语料（缓存优先）→ 默认选中 `sentenceId` 或第一句。
2. 切换等级：过滤本地列表；后台刷新；不打断当前录音。
3. 听示范：`POST /api/tts`（wav，儿童 slow）→ 下载 → AVPlayer；重复点先停再播。
4. 跟我读：播完示范 → 200–300ms → 自动开录；用户只需读。
5. 录音：0.6–60s；停止后立即上传；本地先保留一份用于回放。
6. 提交：`POST /api/attempts`（同步，最长 90s）。
   - 进度文案按耗时切换：“上传录音…”→“识别中…”→“评分中…”→“生成建议…”（不显示假百分比）。
   - 成功：总分/子项/逐词/纠错/语调（成人）；儿童走简化版。
   - `degraded=true`：显示“录音已保存，评测服务暂时不可用”，按钮“重试评测”（`POST /attempts/:id/retry`）。
   - 429：显示 `detail` 剩余时间，禁用录音。
7. 重试评测：不重新录音；成功后替换结果。
8. 下一句：按列表顺序；到末尾提示“这一组读完啦”。

### API

| 时机 | 接口 |
|---|---|
| 列表 | `GET /sentences?level=A1` |
| 示范音 | `POST /tts`（`{text,rate,format:'wav'}`） |
| 提交 | `POST /attempts`（multipart） |
| 重试 | `POST /attempts/:id/retry` |
| 回放 | `GET /audio/:id` 下载后播放 |
| 预热 | `POST /warmup`（可选，静默） |

### 状态

| 状态 | 表现 |
|---|---|
| loading | 句子卡骨架 + 按钮禁用；不整屏白 |
| error | 顶部 banner；录音按钮仍可用（可重录）；提交失败保留本地录音 |
| empty | “这个等级还没有句子，换一个等级试试” |
| 儿童 | 不显示 IPA/低分/F0；总分 <60 只显示鼓励；按钮 56vp；默认慢速 |
| 无语音 | `recognized_text` 为空/过短：显示“没听到你的声音，再试一次”，不显示 0 分热力图 |

## 4. 连读模式

**路由**：`flow?materialId=`
**角色**：所有
**目标**：一次读 5/10/15 句，录完立即下一句，后台评分。

### 结构

```text
┌─────────────────────────────────────┐
│ ← 连读模式                  设置 ⚙ │
├─────────────────────────────────────┤
│ 第 3 / 10 句        [进度条 ███░░]  │
│ “The quick brown fox jumps over…”   │
│ 那只敏捷的棕色狐狸跳过了…            │
│                                     │
│ [🔊 听示范]   [🎤 开始说]            │
│                                     │
│ 已提交 3 · 已评分 2 · 评分中 1       │
├─────────────────────────────────────┤
│ 本组句子（可展开看结果）             │
│ ✅ 1. I like apples.          82    │
│ ⏳ 2. She reads every day.    评分中 │
│ ❌ 3. ...                    重录    │
│                                     │
│ [结束并看汇总]                       │
└─────────────────────────────────────┘
```

### 交互

**Setup（首次）**

- 来源：语料 / 我的书页 / 自己输入 / 拍照识别（`ocr` 能力可用时）。
- 数量：5 / 10 / 15；等级；随机抽句（可选）。
- 拍照识别：`POST /ocr`（≤10MB）；多选图片时逐张识别、显示 k/N；识别文本可编辑；可保存为材料。
- 开始：生成本地 item 列表（`unsent`）。

**Running**

- 录音 → `POST /attempts/async` → 立刻下一句，不等待评分。
- 每句状态：`unsent → pending → scoring → done/failed`；失败显示原因 + “重录这句”。
- 轮询：`GET /attempts/status?ids=...` 每 2s；页面销毁停止；重进恢复。
- 自动下一句可关；关闭后显示“下一句”按钮。
- 录音时长/大小本地校验；不切片。

**Summary**

- 全部提交后显示：完成句数、平均分（成人/儿童规则）、失败列表、重录入口。
- 可保存本次自定义文本为材料（`POST /materials`）。
- 儿童：不显示低分，只显示“完成啦/再练练”；不显示 IPA。

### API

| 时机 | 接口 |
|---|---|
| 语料 | `GET /sentences?level=` |
| 书页 | `GET /materials?kind=page`、`GET /materials/:id` |
| 拍照 | `POST /ocr`；保存 `POST /materials` |
| 提交 | `POST /attempts/async`（multipart） |
| 轮询 | `GET /attempts/status?ids=` |
| 重录 | 直接重新提交（新 attempt） |
| 汇总重试 | 对失败项重新录音提交 |

### 状态

| 状态 | 表现 |
|---|---|
| loading | setup 骨架；running 只在首句显示加载 |
| error | 单句失败不影响其他句；顶部汇总“2 句待重录”；网络恢复后可继续轮询 |
| empty | “这一页没有找到句子，换一页或自己输入” |
| 儿童 | 大按钮、少文字；隐藏“评分中”等技术词，用“正在听…”；不显示低分 |

## 5. 对话训练

**路由**：`chat_scenarios` → `chat_session?sessionId=`
**角色**：所有（儿童受 `allow_free_chat` 限制）
**目标**：在场景里**只用语音**完成 6 轮对话，得到温和纠错与可跟读的回复。

### 5.1 场景列表

```text
┌─────────────────────────────────────┐
│ ← 对话训练                          │
│ 选一个场景，和 AI 聊 6 轮            │
│ ┌─────────┐ ┌─────────┐            │
│ │ 🍔 点餐  │ │ 🏫 学校  │            │
│ │ A2 · 6+ │ │ A1 · 5+ │            │
│ └─────────┘ └─────────┘            │
│ ...                                 │
└─────────────────────────────────────┘
```

- `GET /chat/scenarios`；按年龄过滤由服务端完成；儿童只看到适龄场景。
- 卡片：标题（中英）、setting、level、min_age；点击 `POST /chat/sessions` → 进会话。
- 空：“还没有适合你的场景，让家长看看设置”。
- 关闭自由话题时，服务端强制 child_safe；客户端不显示“自由话题”开关。

### 5.2 会话（语音唯一输入）

```text
┌─────────────────────────────────────┐
│ ← 🍔 At the Restaurant      3/6     │
├─────────────────────────────────────┤
│ 🤖 “Hi! What would you like?”       │
│    [🔊 再听]  [中文]                 │
│                                     │
│ 🧑 “I want a hamburger.”  [🔊]      │  ← 用户语音气泡 + 回放
│    识别：I want a hamburger.         │  ← 识别确认（可重说）
│                                     │
│ 🤖 “Great choice! ... ”             │
│    ✏️ 纠错：I want **a** hamburger.  │  ← 成人显示；儿童温和版
│    💡 可以这样说：...                │  ← 点一下只朗读，不发送
│                                     │
│        [ 🎤 按住说话 / 点击录音 ]     │  ← 唯一输入
└─────────────────────────────────────┘
```

**一轮流程（必须按此顺序）**

1. 录音（0.6–60s）→ 本地文件。
2. `POST /asr`（`language=en`）→ `text`。
3. 显示识别文本，提供“重说 / 发送”；**不自动发送**（避免误识别直接进 LLM）。
4. `POST /chat/sessions/:id/turn`（multipart：`audio` + `text`）。
5. 收到 `reply/reply_zh/correction/suggested_replies/done`。
6. `POST /tts`（`text=reply`, `format=mp3`）→ 下载 → 播放；失败不影响文字展示。
7. 用户录音回放：`GET /audio/:user_message_id` 或本地 pending 文件。

**约束**

- **没有文字输入框**；建议回复 chips 点击只“朗读提示”，不发送；用户必须自己说。
- 一轮未完成前禁用录音；不允许并发 turn。
- 第 6 轮或 `done=true`：展示结束卡“今天聊得很棒”，提供“换个场景/再聊一次”。
- 儿童：纠错只展示 1 条、语气温和；不显示音素；回复语速默认 slow。
- 安全：`flag=unsafe_filtered` 时正常显示安全回复，不展示被过滤内容；`degraded_llm=true` 时提示“今天 AI 有点忙，先用固定话术陪你练”。

### API

| 时机 | 接口 |
|---|---|
| 场景 | `GET /chat/scenarios` |
| 开始 | `POST /chat/sessions` |
| 历史 | `GET /chat/sessions/:id` |
| 识别 | `POST /asr` |
| 一轮 | `POST /chat/sessions/:id/turn` |
| 朗读 | `POST /tts` |
| 回放 | `GET /audio/:id` |

### 状态

| 状态 | 表现 |
|---|---|
| loading | 场景骨架；会话首条“正在准备场景…” |
| error | ASR 失败：保留录音，“再说一次”；turn 失败：不重复发送，显示“重试这一轮”；TTS 失败：文字照常，显示“再读一遍” |
| empty | 无场景/无消息 |
| 儿童 | 大按钮、慢速、温和纠错；不显示低分/IPA；不显示“自由话题” |

## 6. 故事 / 材料

**路由**：`story_list`、`story_create`、`story_detail?materialId=`
**角色**：所有
**目标**：中文故事 → 适龄英文 → 连读/复述/插画；拍照书页 → 保存 → 连读。

### 6.1 故事列表

```text
┌─────────────────────────────────────┐
│ ← 我的故事                 [+ 新建] │
│ [全家] [只看我的]    故事 / 书页     │
│ ┌─────────────────────────────────┐ │
│ │ [封面图] The Lost Kitten   A2   │ │
│ │ 8 句 · 爸爸 · 10-30             │ │
│ └─────────────────────────────────┘ │
│ ...                                 │
└─────────────────────────────────────┘
```

- `GET /materials?kind=story|page`；家庭共享。
- 封面：`has_image=true` 时下载 `/materials/:id/image`（带 Cookie）→ PixelMap；无图用渐变占位。
- 点击进详情；长按/更多：编辑/删除（创建者或家长；服务端 403 兜底）。
- 空：“还没有故事，点右上角用一个中文故事换英文绘本”。

### 6.2 新建故事

```text
┌─────────────────────────────────────┐
│ ← 新故事                            │
│ 用中文讲讲你的故事                   │
│ [ 大文本框                     ]     │
│ [🎤 说中文]  0/2000                 │
│ 难度 A1 A2 B1 B2                    │
│ ☑ 把 weakest 音练进故事（成人）      │
│ [ 生成英文故事 ]                     │
│                                     │
│ ── 结果（可编辑）────────────────── │
│ Title: The Lost Kitten              │
│ 1. ...  / 中文对照                   │
│ [🔊 听] [编辑]                       │
│ [保存并去连读] [画一张插画]           │
└─────────────────────────────────────┘
```

- 中文输入：打字或 `POST /asr`（`language=zh-CN`）追加；≤2000 字。
- 生成：`POST /story/rewrite`（`text_zh/level/max_sentences/use_weak_phonemes`）。
  - 60s 内可能较慢：显示“正在把故事变成英文…”，不显示假进度。
  - 503 `story_unavailable`：提示“可以先自己写英文”，切手动输入。
- 结果：`title_en/sentences/text_en/readability/warnings/weak_phonemes_used`；可编辑英文句子。
- 保存：`POST /materials`（`kind:'story'`, `source_zh`, `level`）→ 跳 `flow?materialId=` 直接连读。
- 插画：保存后异步 `POST /story/:id/illustrate`（失败不影响阅读）；详情页可“换一张”（`force:true`，有费用提示）。
- 儿童：隐藏 `readability`/weak phonemes 技术细节；文案“讲个故事，AI 帮你变成英文绘本”。

### 6.3 故事详情 / 复述

```text
│ [插画]                              │

└─────────────────────────────────────┘
```

- 句子朗读：逐句 `POST /tts`（mp3），可预取下一句。
- 复述：
  1. 录音 → `POST /asr`（`language=en`）→ `transcript`；
  2. `POST /story/retell`（`material_id/story_sentences/transcript/level`）；
  3. 展示 `coverage/covered_points/missing_points/feedback_zh/feedback_en`；**不显示发音分**。
- 503 `retell_unavailable`：提示“先读给爸爸妈妈听”。
- 儿童：只显示“讲到了/还可以讲”，不显示百分比低分；不显示 IPA。

## 15. 验收口径（页面级）

- [ ] 每个页面都有 loading / error / empty 三态，且不是同一句“加载失败”。
- [ ] 每个错误都能对应到一个可执行动作（重试/去设置/换等级/回首页）。
- [ ] 儿童页面无 IPA、无 <60 数字、无 F0 曲线、按钮 ≥56vp。
- [ ] 家长页面 child 无法通过深链进入（客户端拦截 + 服务端 403）。
- [ ] 所有音频播放走“下载后本地播放”，不直接把需要 Cookie 的 URL 交给 AVPlayer。
- [ ] 所有写操作（评测/对话/改写/插画）在按钮 loading 期间不可重复点击。
- [ ] 所有页面在切后台/销毁时停止轮询、播放、下载。
