# 路线图 · M0–M4

> 原则：每个里程碑都**可独立验收、可独立使用**；不把“全部做完”作为一个里程碑。
> 工期是单人开发的粗略估计，仅用于排期，不是承诺。
> 所有“真机可用”结论必须来自验收记录，不能来自文档假设。

---

## 0. 总览

| 里程碑 | 主题 | 估算 | 关键产出 | 依赖 |
|---|---|---|---|---|
| **M0** | 登录 + 跟读 | 2–3 周 | 可登录、选句、录音、同步评分、看结果 | 后端现有 API + Token 三端点（P0） |
| **M1** | 连读 + 对话 | 2–3 周 | 异步评分、轮询、语音对话闭环 | M0；对话已核实为 ASR→turn→TTS 三步 |
| **M2** | 故事 + 插画 | 2–3 周 | 中文故事→英文、材料库、OCR、复述、插画 | M1；voice OCR/LLM/Image 能力 |
| **M3** | 盲测 + 诊断 + 家长 | 2–3 周 | 盲测周报、诊断/错音本、家长面板、成员管理 | M0–M2；家长 API |
| **M4** | 打磨与发布 | 2–3 周 | 深色/平板/无障碍/性能/签名/隐私合规 | 全部；分发方式拍板 |

> 总计约 10–15 周（单人、含真机联调）。若只能投入业余时间，按 1.5–2 倍估。

## M0 · 登录 + 跟读

### 范围

- DevEco 工程：`entry` + `commons/net`、`commons/audio`、`commons/storage`、`commons/design`。
- 登录/登出/会话恢复；Bearer Token（access 1h / refresh 30d，单飞刷新、一次性轮换）+ Asset Store。
- 依赖后端 P0：`/auth/token`、`/auth/refresh`、`/auth/revoke` 先落地；未落地前 M0 只能做 UI 与 Fake。
- 启动健康检查 `/health`；NAS 不可达提示。
- 语料列表 + 等级切换 + 本地缓存。
- AVRecorder 录音（m4a / AAC-LC / 16kHz / 单声道 / 65kbps）、AVPlayer 播放 TTS/回放。
- 同步 `POST /attempts`；结果页（成人完整/儿童简化）。
- 错误映射、loading/empty/error、429 用量。
- 首次启动隐私说明（按 mock/local/hybrid/cloud 动态文案）。
- 基础设置（语速/退出/清缓存）。

### 交付物

- 可安装 HAP（debug 签名）。
- `entry` 壳 + `features/auth`、`features/practice`。
- `commons/net` HttpClient/TokenSession/ApiError（含单飞刷新）。
- `commons/audio` Recorder/Player/Coordinator。
- 单元测试：DTO/错误映射/VM（Fake HTTP）。
- 真机验收记录（机型/系统版本/结果）。

### 验收标准

**功能**

- [ ] 正确账号可登录（`POST /auth/token`）；错误密码显示“邮箱或密码不正确”。
- [ ] 杀进程重开仍登录：access 过期时自动 refresh；refresh 30 天内有效。
- [ ] access/refresh 都在 Asset Store（`ec_access_token`/`ec_refresh_token`），不出现在 Preferences/日志；退出后两个都删除。
- [ ] 并发 3 个请求同时 401 → 只发 1 次 `/auth/refresh`，三个请求都重放成功。
- [ ] refresh 返回 401（被吊销/轮换失效）→ 清 token → 登录页；refresh 网络失败 → 不清 token，提示重试。
- [ ] 退出登录调用 `/auth/revoke`（失败也清本地），再进入 App 不需要旧 token。
- [ ] 语料 A1–B2 可切换；断网时显示缓存 + “离线内容”标识。
- [ ] 录音 0.6–60s；文件为 m4a / AAC-LC / 16kHz / 单声道 / 65kbps；≤12MB；服务端评测成功返回分数。
- [ ] 60s 文件约 0.49MB（±20%），与服务端解码出的时长一致。
- [ ] “听示范”可播 wav；“跟我读”播完自动开录；录音时不能同时播放。
- [ ] 结果页成人：总分/子项/逐词/纠错/语调；儿童：无 IPA、无 <60 数字、大按钮。
- [ ] `degraded=true` 时显示“录音已保存，可重试”，`POST /attempts/:id/retry` 可恢复。
- [ ] 429 显示剩余时间并禁用录音；次日恢复。
- [ ] 拒绝麦克风后可引导到设置；授权返回可录。

**质量**

- [ ] 冷启动到首页 ≤3s（中端真机，目标值，实测记录）。
- [ ] 连续 20 次录音/播放无 fd 泄漏、无崩溃。
- [ ] 所有页面三态齐全；错误文案可执行。
- [ ] 无第三方运行时依赖。

**隐私**

- [ ] 首次启动展示隐私说明；拒绝麦克风不影响只读功能。
- [ ] 不申请 CAMERA/位置/通讯录。
- [ ] 登出清空 pending 录音与音频缓存。

### 不做

- 连读/异步评分、对话、故事、盲测、家长面板、深色模式、平板双栏。

### 风险

| 风险 | 缓解 |
|---|---|
| 16k AAC 截掉部分高频辅音，PA 评分偏低 | 固定参数做真机语料对比；异常时再评估，不静默换码率 |
| 后端 Token 接口未按期落地 | M0 用 Fake 网络层先做 UI；Token 契约先冻结，避免二次返工 |
| 并发刷新/轮换竞态 | 单飞 Promise + 每请求最多重放一次；401 只清一次 token |
| 真机录音路由问题 | 耳机/外放/蓝牙矩阵；提前借设备 |
| 隐私文案与 hybrid 部署不符 | M0 就如实写“会经 NAS 转发到云端”；不承诺本地处理 |

## M1 · 连读 + 对话

### 范围

- 连读 setup（数量/来源/自定义/拍照识别可选）。
- `POST /attempts/async` + `GET /attempts/status` 轮询；失败重录；汇总。
- 对话场景列表、会话、语音唯一输入。
- ASR → turn → TTS 三步闭环；纠错卡；6 轮结束。
- 录音/播放互斥在长会话中的稳定性；轮询恢复。
- 用量在连读/对话中的累计与 429。

### 交付物

- `features/flow`、`features/chat`。
- `commons/net` 增加批量轮询/取消。
- 对话服务 `ChatService.turnByVoice()`（内部三步，未来可替换为后端一体化）。
- 验收记录：10 句连读、6 轮对话、弱网恢复。

### 验收标准

- [ ] 连读 10 句：录完立即下一句，不被评分阻塞；UI 显示每句状态。
- [ ] 轮询 2s；全部完成后显示汇总；页面退出再进可恢复未完成 ids。
- [ ] 单句失败可“重录这句”；不重复提交已成功句。
- [ ] 录音不切片；一次上传一整段；服务端识别完整（含句尾停顿）。
- [ ] 对话只能语音输入：无文字键盘；建议回复只朗读不发送。
- [ ] 一轮：ASR 成功 → 确认文本 → turn → TTS 播放；失败可重试且不重复 turn。
- [ ] turn 响应没有 TTS 音频；TTS 由客户端单独 `POST /tts` 获取，失败不影响文字。
- [ ] turn 后轮询 `GET /chat/sessions/:id/messages` 补 `pron`：成人显示小分、儿童只用于鼓励；3–5 次未到不报错、不阻塞下一轮。
- [ ] 6 轮结束显示结束卡；儿童慢速、温和纠错、无 IPA。
- [ ] 对话中录音/播放不冲突；切后台停止。
- [ ] 连读/对话触发 429 时正确停止并提示。

**质量**

- [ ] 连续 10 句连读 + 6 轮对话无崩溃/无内存飙升。
- [ ] 弱网（丢包/延迟）下轮询可恢复；不重复计费。
- [ ] TTS 缓存命中首播 ≤500ms（目标，实测记录）。

### 已核实（非阻塞）

> **现有 `/chat/sessions/:id/turn` 需要 `text`，不内部 ASR、不返回 TTS 音频。** 移动端必须三步调用；这是已核实的接口事实，不是待定问题。
> 发音分不在 turn 响应，也不在 `/sessions/:id`，只在 `GET /chat/sessions/:id/messages` 的 `pron`，且由 `after()` 异步写入，需要轮询。
> 若希望“一轮一请求”，需后端把 ASR/TTS 收进 `/turn`【待后端新增】。M1 按三步实现，不阻塞；延迟需在真机上实测（2–3 次请求）。

### 不做

- 故事、盲测、诊断、家长面板。

## M2 · 故事 + 插画

### 范围

- 材料库：列表/详情/删除/图片鉴权下载。
- 中文故事输入（打字/语音 zh-CN）→ `/story/rewrite` → 可编辑英文 → 保存 → 连读。
- 插画：`/story/:id/illustrate`，失败不影响阅读；“换一张”费用提示。
- OCR：拍照/相册/HEIC 能力判断；识别文本编辑；保存书页。
- 复述：录音 → ASR(en) → `/story/retell` → 覆盖度/反馈；不评发音分。
- 故事列表封面/作者/等级/句数；家庭共享。

### 交付物

- `features/story`。
- `commons/net` 图片鉴权下载 + PixelMap 解码。
- 验收记录：中文 2000 字 → 英文 6 句；保存 → 连读；OCR 书页；复述。

### 验收标准

- [ ] 中文 ≤2000 字可改写；`level` A1–B2；`max_sentences` 6；结果可编辑。
- [ ] 保存后跳连读，句子切分正确；`kind=story` 列表可见。
- [ ] 插画成功显示；失败/503/400 有可读提示；不阻塞阅读。
- [ ] 图片通过带 `Authorization` 的下载 + PixelMap 显示；不直接用 `Image(url)`。
- [ ] OCR ≤10MB；HEIC 能力为 false 时上传前拦截；503 可切手动输入。
- [ ] 复述显示覆盖度/讲到了/可补充；不显示发音分。
- [ ] 儿童：故事/复述页面无 IPA、低分不显示、大按钮。

**质量**

- [ ] 改写 60s 内完成或超时提示；不自动重复调用（费用）。
- [ ] 插画 90s 超时；重试按钮显式。
- [ ] 图片缓存 LRU，不无限增长。

### 风险

| 风险 | 缓解 |
|---|---|
| LLM 改写慢/失败 | 进度文案 + 503 可切手动；不自动重试 |
| 插画费用/内容审核 | 显式按钮 + 费用提示；`content_unsafe` 文案 |
| HEIC 解码不支持 | 能力开关 + 上传前拦截 |
| 大图 OOM | 上传前压缩；显示用采样 PixelMap |

## M3 · 盲测 + 诊断 + 家长

### 范围

- 盲测：开始/恢复、10 句、异步提交、进度、结束、周报历史；全程无分数。
- 诊断：`/diagnosis` 摘要/音素卡/趋势/强化练习；儿童无 IPA。
- 错音本：`/review` 待复习/SRS 评分/高频错词。
- 家长面板：全家汇总、孩子剩余时长、盲测周环比、成员管理、重置密码、建议收件箱。
- 设置完善：修改密码入口、隐私说明、建议提交。
- 权限：家长路由守卫 + 服务端 403 双保险。

### 验收标准

- [ ] 盲测进行中**任何接口/页面都不出现分数**（抓包 + UI 走查）。
- [ ] 结束前 `finish` 按钮可用；结束后显示平均分/环比；`pending>0` 有说明。
- [ ] 同一组句子可复用；下周对比有意义。
- [ ] 诊断 weak/watch/ok 排序；强化练习带 focus 进入练习页。
- [ ] 错音本评分后下次复习时间更新；儿童文案温和。
- [ ] 家长可创建/编辑成员、重置密码；儿童无法进入家长面板（深链也 403）。
- [ ] 盲测周环比在家长面板可见；无数据空态。
- [ ] 建议提交成功；家长可标记 read/resolved。

**质量**

- [ ] 盲测 10 句 + 轮询 2 分钟无崩溃。
- [ ] 家长面板 1 屏内看到关键数字；平板 2 列。
- [ ] 儿童路径无 IPA（自动化扫描 + 人工）。

### 安全/合规缺口（需拍板）

- 修改密码后旧 refresh token 不失效（服务端未吊销）。
- 无“注销全部设备”接口。
- 无用户自助删除数据入口。
- 家长可查看孩子全部数据；需家长须知明确。

## M4 · 打磨与发布

### 范围

- 深色模式（按资源限定符）、平板双栏、横屏策略。
- 无障碍：字体缩放、对比度、屏幕阅读器、减少动效。
- 性能：冷启动、列表滚动、图片/音频内存、fd 泄漏。
- 离线体验：语料/材料缓存、pending 录音恢复、离线提示。
- 发布：应用图标/名称/启动图、release 签名、隐私政策 URL；iOS 走 TestFlight，鸿蒙分发方式【待用户确认】。
- 可选：证书 pinning、对话一体化（若后端新增）、TTS 预取优化。
- 文档：运维/隐私/故障排查手册。

### 验收标准

- [ ] 冷启动 ≤3s、页面切换 ≤300ms（目标，实测）。
- [ ] 10 分钟连续使用内存稳定（无持续增长）；无 fd 泄漏。
- [ ] 深色模式所有页面/图表/分数可读；儿童模式仍成立。
- [ ] 平板 840vp 无横向滚动；练习页双栏。
- [ ] 字体 1.3× 无截断；系统屏幕朗读（无障碍）可读主要操作。
- [ ] release 包无明文 HTTP、无 debug 入口、无日志泄露 token。
- [ ] 隐私政策/权限说明/儿童说明齐全；按所选分发方式（内部/内测）准备的材料齐全。
- [ ] 安装/升级/卸载重装流程正常；卸载后 token 不残留。

### 分发决策（阻塞发布）

- **iOS：TestFlight**（已定）。需要 Apple Developer 账号、App Record、外部测试组与审核；服务只在家庭网络可达时，测试者必须在家里的 Wi-Fi/VPN 下使用。
- **鸿蒙：【待用户确认】**。两个务实选项：
  1. **内部签名 / 企业内部分发（建议首发）**：家庭/亲友少量设备，快、不等审核；代价是证书/Profile 有效期、设备管理、无法公开分发。
  2. **应用市场内测（AppGallery 内测）**：能自动更新、路径正规；代价是审核材料（隐私政策、软著/备案、隐私检测、儿童应用要求），且审核员可能因“服务仅内网”无法访问。
- 若上架/内测：隐私政策、软著/备案、隐私检测报告、域名/ICP、儿童应用审核；
- 若内部：设备 UDID/证书有效期/安装说明。

见 [open-questions.md](open-questions.md) Q3。

## 1. 跨里程碑 Definition of Done

每个功能必须同时满足：

1. **功能**：主路径 + 至少 3 个异常路径（网络/权限/429/503）都走通。
2. **状态**：loading / error / empty 三态齐全；错误有可执行动作。
3. **儿童**：IPA/低分/大按钮规则走查。
4. **隐私**：不新增权限；不新增三方 SDK；日志脱敏。
5. **测试**：VM/Service 单测；真机至少 1 台；录音/播放至少 1 次耳机场景。
6. **文档**：API/错误码/页面说明同步更新；未验证项标注【待真机验证】。
7. **性能**：无应用无响应/明显卡顿；无未释放的 fd/播放器。

## 3. 风险登记（跨里程碑）

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|
| 隐私文案与 hybrid 部署不符（数据会离开家庭网络） | 高 | 高（隐私承诺/上架） | 如实文案；要“完全本地”需切 local（未部署）；见 open-questions Q1 |
| 对话三步调用延迟高 | 中 | 中（体验） | 先做 ASR 确认；推动后端一体化 |
| 16k AAC 的 PA 评分偏差 | 中 | 中 | 固定 16k/65k；真机语料对比；不静默换码率 |
| 后端 Token 接口延期 | 中 | 高（阻塞 M0） | 先冻结契约 + Fake；M0 前完成 P0 |
| 域名只在家可达 | 高 | 高（上架审核/外网演示） | 明确“家庭内使用”；应用市场说明；VPN/内网穿透另议 |
| 无用户删除数据接口 | 高 | 中（合规） | 运维脚本兜底；后端补接口 |
| 修改密码不踢旧会话 | 中 | 中（安全） | 后端补 logout-all；短期提示 |
| 平板/深色拖到后期 | 中 | 低 | token 化先行；M4 集中 |
| 第三方依赖诱惑 | 低 | 中 | 零三方原则；评审把关 |

## 4. 建议排期（单人，非承诺）

```text
第 1–3 周   M0：工程/登录/录音/跟读/结果
第 4–6 周   M1：连读/轮询/对话（ASR→turn→TTS）
第 7–9 周   M2：故事/材料/OCR/复述/插画
第 10–12 周 M3：盲测/诊断/错音本/家长
```
