# 客户端验收清单（从 Web 端守卫脚本提炼）

Web 端有一批自动化守卫（`check:practice-ui` / `check:flow` / `check:chat-speech` / `check:child-ipa` / `check:story` / `check:family` / `check:encouragement` 等）。
它们断言了大量**产品语义**，原生客户端可以直接把它们当作「真机验收清单」。

> 原则：**宁可少功能，不可静默失败；儿童可见载荷零 IPA；分数不打击孩子。**

---

## A. 通用（每屏）

- [ ] loading 有明确文案（不是空白屏）
- [ ] empty 有人话 + 主操作
- [ ] 网络错误**可见**（不是只打日志/无反应），且可重试
- [ ] 401 → 跳登录（登录后回到原页面）
- [ ] 服务端 503（provider 不可用）显示可读提示，**不把降级结果当正常结果**
- [ ] 返回/关闭不丢已提交的异步任务（连读场景）
- [ ] 录音中切后台/来电：安全停止并提示（不产生 0 秒空录音提交）

## B. 录音与播放

- [ ] 首次录音弹出麦克风权限；拒绝后给「去设置开启」的引导
- [ ] 录音时长 < 600ms 视为误触，不提交
- [ ] 单次录音上传 < 12MB
- [ ] **录音前停止播放**（否则蓝牙切通话模式导致声音变闷）
- [ ] 录音格式 m4a/AAC 16kHz 单声道（真机验证服务端可解码）
- [ ] 播放失败有提示；回放 `<audio>` 不出现 `0:00 / 0:00`

## C. 跟读练习

- [ ] 「跟我读」：播完示范音**自动开录**（不需要再点一次）
- [ ] 「只听示范」：**点击立即播放**（不是只显示一个播放器）
- [ ] 音素级热力图按 `capabilities.phoneme_level` 自适应（不支持时不硬画）
- [ ] `prosody = null` 的轴显示「—」，**不画成 0 分**
- [ ] 词级反馈用**长度编码**而非仅颜色（色盲可用）
- [ ] 整句没听到（`recognized_text` 极短/`low_snr`）→ 显示「没听到」提示，**不展示满屏 0 分**
- [ ] 儿童模式：**不显示 IPA**、不显示低分、只有鼓励

## D. 连读模式

- [ ] 录完一句**立即跳下一句**（不等评分）
- [ ] 轮询 1–2s 更新「待评分 → 评分中 → 分数」，**不阻塞 UI**
- [ ] 全部读完显示汇总（平均分、最差 2–3 句）+ 鼓励语
- [ ] 中途退出后已提交的仍在后台评分（下次进入能补拉）

## E. 对话训练

- [ ] **没有文字输入框**（只有语音）
- [ ] 提示句点击 = **开始录音**（不发送文本）
- [ ] 麦克风不可用时**醒目报错** + 4 步排查，恢复后自动消失
- [ ] 助手回复可重播；每轮用户消息有录音回放
- [ ] 历史里：家长可见发音分数；**儿童只见鼓励语、无分数**

## F. 故事模式

- [ ] 中文输入支持 🎤 语音（`language=zh-CN`）与文字
- [ ] 难度可选 A1–C1，默认取账号 `cefrLevel`
- [ ] 改写结果**对照展示**（你说 / 英文），英文可编辑
- [ ] `warnings:["too_hard"]` → 提示「要不要再简单一点」
- [ ] 保存后跳连读；读完有鼓励语
- [ ] 复述：**先鼓励 → 再一条建议**；**不显示发音分**
- [ ] 插画：失败可见原因 + 重试；不写半截文件
- [ ] 故事集：按日期分组、连续天数、只看我的

## G. 儿童保护（硬要求）

- [ ] 儿童可见页面**零 IPA 字形**（Web 端有 `check:child-ipa` 自动扫描，客户端需自查资源与文案）
- [ ] 文案**不含否定词**（差/错/失败/不行…）用于分数反馈时
- [ ] 不显示与其他孩子的比较
- [ ] 家长面板/家庭成员/建议仅家长可见（客户端隐藏 + 服务端 403 双保险）

## H. 家长面板

- [ ] 趋势与掌握度正确（null 不当 0）
- [ ] 家庭成员：可创建（含 CEFR）、可改水平、可重置密码；重复登录名/短密码有可见错误
- [ ] 建议列表可导出（Markdown/JSON）

---

## 真机必测（模拟器不够）

| 项 | 为什么 |
|---|---|
| 麦克风录音 + 上传 + 回放 | 采样率/编码差异只会在真机暴露 |
| 蓝牙耳机录音/播放切换 | 通话模式会让音频变闷，模拟器无法复现 |
| 后台/锁屏 | 录音中断、播放继续 |
| 局域网 HTTPS 证书信任 | 自签证书在设备上的信任流程 |
| 弱网（限速/断网重连）| 异步任务重试与轮询 |
| 平板/横屏（若支持）| 布局与按钮尺寸 |
